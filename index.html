Fitment Test Cases

MVP 2 · 6 test cases

Validation scenarios

Open a case to see the test input and expected result.

01Approve a complete kit
Test input
Two front struts and two rear shocks match the target vehicle configuration and required positions.
Expected result
Approve the kit and return the configuration that can be advertised.
02Catch a drivetrain mismatch
Test input
All four parts match the model and year, but one shock fits AWD and the kit is advertised for FWD.
Expected result
Reject the FWD configuration and identify the conflicting SKU and drivetrain attribute.
03Detect an incorrect position
Test input
The kit contains two front-left struts, and the catalog distinguishes left from right.
Expected result
Flag the duplicate front-left position and the missing front-right strut.
04Flag a missing component
Test input
The kit definition requires two rear shocks, and the kit contains one.
Expected result
Show the expected quantity of two, the actual quantity of one, and identify the missing rear shock.
05Narrow the advertised model years
Test input
Three components fit 2018–2021. The fourth fits 2019–2020 for the same vehicle variant.
Expected result
Return 2019–2020 as the shared fitment range and flag 2018 and 2021 for removal.
06Escalate missing fitment data
Test input
A SKU exists in the catalog, but its fitment for the target configuration is missing.
Expected result
Mark the kit as pending review and identify the fitment data the operator needs to confirm.
